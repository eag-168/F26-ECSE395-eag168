This is my last lab working with the ESP32, and it is focusing on integrating actuators and sensors. I am uploading the code from my Mac to my ESP32 using Visual Studio Code and PlatformIO IDE. The code that integrates the **photoresistor module** and the **traffic light module** can be found in ***Traffic resistor.cpp***.

To complete this lab, I made a light meter. My code reads the photoresistor as an analog value, then uses a traffic light module and buzzer module to indicate how bright the light is. The brightest values cause a high note (*C5*) and a green light, the medium values cause a medium note (*C4*) and a yellow light, and the low values cause a low note (*C3*) and a red light.
